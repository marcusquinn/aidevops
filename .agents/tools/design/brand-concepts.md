# Brand Concepts

<!-- AI-CONTEXT-START -->

- **Use for**: New identity, rebrand, logo directions or a brand concept board;
  not an excuse to rebrand a small UI repair.
- **Owners**: `brand-identity.md` owns strategic identity in the project's
  `context/brand-identity.toon`; `design-md.md` owns accepted implementation tokens.
- **Boundary**: A concept board is a proposal, not a production kit, accessibility
  certificate or trademark clearance. Read-only audits/studies remain read-only.
- **Production**: `visual-concepts.md` for optional image generation and approval;
  `content/production-image.md` for assets. [Taste assessment](taste-skill.md)
  records source, adaptations and licence; no upstream install is needed.

<!-- AI-CONTEXT-END -->

## Develop a direction

Read existing brand/design files, audience, product purpose, differentiation,
voice, required applications and rights constraints. Reuse the supplied brief;
ask only for consequential missing context or taste. Separate facts from proposed
positioning. Preserve existing assets unless rebranding is authorized.

Write one sentence connecting a **core idea** to the audience's experience. Derive
type, shape, imagery and applications from it rather than choosing unrelated
decorations. It need not be a literal pictogram: a wordmark or typographic system
can carry the idea better than a symbol.

When direction is open, offer a small bounded set of genuinely different concepts,
not colour swaps. For each record the idea, audience fit, trade-off and strongest
application. Narrow already accepted directions instead of restarting exploration.

For mark exploration, use only techniques that fit the idea:

| Technique | Question |
|-----------|----------|
| Monogram with meaning | Can a letter carry a relevant action or attribute? |
| Product action | Can the thing the product does become a simple gesture? |
| Metaphor fusion | Can two relevant ideas combine into one readable silhouette? |
| Negative space | Does a second reading add meaning without harming recognition? |
| Construction geometry | Can repeatable proportions make the mark coherent? |

Do not force every technique, invent a mathematical construction story, or imitate
a competitor's mark. Distinctive-looking is not evidence of legal availability;
route actual clearance to legal review before consequential launch use.

## Present a concept board

Keep comparisons at the same scale, on neutral backgrounds, with readable labels.
Choose applications relevant to the business rather than a fixed stationery kit.

- Direction name and one-sentence idea; proposed versus existing choices.
- Primary mark/wordmark, simplified small-size and monochrome explorations.
- Type roles, palette roles and representative foreground/background pairs.
- One or two realistic applications demonstrating the system, not decorative
  mockups that obscure the mark. Use real copy or clearly labelled placeholders.
- Rationale, sources/rights, uncertain details and production work still needed.

Accompany images with a readable text description and actual proposed token values;
image text, colour sampling and generated font labels can be inaccurate. Compare
legibility at small sizes, meaningful contrast and colour-independent recognition.
Brand-mark exemptions do not exempt adjacent UI, links, body copy or controls.

## Select and hand off

Obtain direction selection when the user reserved that decision. Concept approval
does not authorize implementation, purchases or publication. Keep alternatives in
the existing authorized brief/artifact area; do not create a second token schema
or write speculative choices into canonical brand/design files.

Once adoption is authorized, promote accepted strategy to
`context/brand-identity.toon` and validated tokens/rationale to `DESIGN.md` through
their owners. Preserve provenance and explain accessibility-driven adaptations.

Before calling the result a **production identity kit**, verify:

- Editable/vector master assets with clean geometry and correct names; a generated
  raster board or automatic trace alone is not an approved logo master.
- Approved full, compact, monochrome and reversed variants as needed; clear space,
  minimum size and examples that remain legible in actual intended use.
- Licensed/available fonts, fallback typography, asset rights and any required
  trademark clearance. List unknowns rather than implying clearance.
- Contrast-tested semantic colour pairs and light/dark variants where applicable;
  colour is not the only indicator of state or meaning.
- Actual exports opened and checked, usage rules and durable source paths. Use
  existing brand-guideline exports only after the canonical system is accepted.

Report the delivered level explicitly: concept, selected direction, implementation
system, or production kit. Missing production checks keep the latter incomplete.
