## Fit and useful additions

The reviewed default frontend skill is experimental v2, approximately 87 KB. Its
marketing-oriented scope explicitly excludes dashboards, data tables, multi-step
product UI and native mobile. Do not load the collection as a universal authority.

| Upstream evidence | Existing aidevops owner | Adaptation |

| `skills/brandkit/SKILL.md`: core idea, mark exploration, applications | `brand-identity.md` | `brand-concepts.md`: concrete direction boards, selection and explicit production-kit boundary |
| `skills/image-to-code-skill/SKILL.md`: reference interpretation and implementation handoff | `design-md.md`, `design-md-from-links.md`, `distinctive-ui.md` | `visual-concepts.md`: optional approval path, observed/proposed/accepted evidence and faithful implementation |

The collection's imagegen web, redesign, GPT, soft/minimal/brutalist, Stitch and
output variants were also considered. Existing image production, design library,
artifact routing and implementation owners cover much of that surface; no duplicate
style collection or new generator/runtime interface is justified by this review.

## Deliberate departures

- Generation is optional, rights/privacy/cost bounded and provider-neutral; no
  install, purchase or repeated regeneration merely because upstream says so.
- No mandatory motion/GSAP, image per section, simulated random selection or
  arbitrary font, punctuation, grid or component bans. Context beats taste rules.
- Canonical identity remains `context/brand-identity.toon` and accepted tokens/
  rationale remain `DESIGN.md`; no hidden design bible or parallel schema.
- Boards are concepts, not vector masters, licensed fonts, trademark clearance
  or verified UI. Generated labels/copy and inferred tokens are not factual proof.
- Accessibility, real behaviour and platform constraints override imitation.
  Correct palette guidance and the existing contrast CLI support this boundary;
  no second accessibility harness is introduced.
- Audits/studies remain read-only, including when canonical brand files are absent.
  Production rendering/behaviour must be tested by existing verification owners.
