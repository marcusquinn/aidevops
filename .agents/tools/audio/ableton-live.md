# Ableton Live

The candidate `ahujasid/ableton-mcp` documents default-on telemetry. Disable it
and verify the inspected revision, actual exports, installed Live version, control
surface, and transport before connecting. Aidevops does not install or open Live,
Max devices, plugins, packs, or the adapter.

Work on a new Live Set version. Record tempo, sample rate, routing, plugin/sample
provenance, frozen/printed dependencies, arrangement, loudness target, and export
settings. Keep one writer and read track/device/transport state before and after
automation. Verify missing media/plugins, clipping, duration, format, loudness,
and a representative listening pass; a completed export alone is insufficient.

The optional `ableton-live` MCP profile accepts only an absolute explicitly
configured executable after operator approval, isolation, and telemetry opt-out.
It refuses headless worker sessions and missing prerequisites. Connect only from
the `ableton-live` focused agent, inspect actual tools, apply bounded changes,
read state back, and disconnect. Rights, paid services, app/plugin installation,
publication, and independent desktop control require separate authority.
