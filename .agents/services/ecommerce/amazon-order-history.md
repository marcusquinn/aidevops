# Amazon Order History MCP

Use only for an explicitly requested export of the operator's own order data. Connect the scoped `amazon-order-history` MCP on demand, verify the requested date range and destination, and keep personal order data out of issues, PRs and public logs. The local server must already be installed; never install it automatically. Disconnect after use.
