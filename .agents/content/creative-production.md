# Focused Creative Production

<!-- AI-CONTEXT-START -->

## Brief and mode

Record the objective, audience, deliverables, constraints, references, rights,
budget, deadline, source provenance, and acceptance evidence. Select one mode:

| Mode | Intended outcome | Minimum evidence |
|---|---|---|
| Draft idea | Reversible exploration | Assumptions, source recipe, reviewable draft |
| Presentation | Communication-quality output | Technical validation plus visual/listening review |
| Dimensionally accurate | Declared geometry/timing/audio constraints | Units and tolerances plus measured checks |
| Fabrication/construction package | Inputs for qualified downstream review | Dimensionally accurate evidence plus explicit unresolved certification |

The requested mode and achieved verification are separate fields. Proceed with
reversible assumptions when safe; request only material missing information.
Generated targets never override measured constraints, and render fidelity never
proves dimensional accuracy.

## Execution contract

1. Preserve originals and calibration/provenance. Ordinary video does not imply
   LiDAR or depth; capture data is opt-in and retains uncertainty.
2. Bound each app specialist to the brief, selected references, current artifact
   state, and its own tools. A fresh Task must retain relevant safety and project
   instructions rather than acting as a stripped system prompt.
3. Use one writer for each native project. For hybrid MCP/API and UI work, read
   state before and after every mutation and stop on mismatch or unknown completion.
4. Distinguish headless execution, independent desktop input, and OS isolation.
   Never certify one property from another.
5. Before external execution, verify the installed adapter/app version and actual
   exports, require applicable approval and isolation, then quote billable cost
   range and ceiling. Never infer subscription percentages from token counts.
6. Store code, parameters, stable IDs, decisions, and verification in Git. Use
   locking or managed asset storage for native binaries and large media; reconcile
   manual edits with the rebuild recipe.
7. Verify the actual artifact: inspect geometry/dimensions and renders, video
   frames/timing/audio, or audio format/meters/listening evidence as applicable.

## Visual iteration

Adapt the Dream Loop pattern as target -> bounded draft -> independent critic ->
measured revision. Image generation is optional and separately authorised;
pixel-perfect imitation is not a default objective. Record critic observations
and changed parameters rather than repeatedly regenerating without evidence.

<!-- AI-CONTEXT-END -->

No workflow here authorises publication, paid generation, cloud rendering,
application installation, desktop takeover, fabrication, or construction use.
