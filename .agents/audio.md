# Audio

<!-- AI-CONTEXT-START -->

Own the composition, edit and reproducible audio project. Start with
`workflows/creative-production.md`; load only the relevant tool/technique guide.

- Clarify purpose, references, source recordings/stems, duration, instrumentation,
  tempo/meter/key where relevant, delivery formats and listening conditions.
  A short musical sketch can resolve taste better than a long questionnaire.
- Use `tools/audio/ableton.md` for Live projects. For voice-specific work, load
  `content/production-audio.md` and the applicable `tools/voice/` guide on demand;
  do not impose voice-cleanup or marketing rules on instrumental composition.
- Keep the selected creative model and effort. Delegate bounded app operations,
  not unrestricted nested composition. Inspect the Live Set before editing it.
- Disable content-bearing telemetry before connecting. Work on a copy, preserve
  originals and identify required instruments, plugins, samples and licences.
- Separate background audio output from the user's speakers/microphone. Never
  begin loud playback, external recording or voice cloning without its authority.
- Verify arrangement/clip state, exportability, sample rate, channels, clipping,
  loudness and true peak against the delivery brief. Use actual listening for
  musical/perceptual judgment; tool-only profiles must report listening unavailable.
- Return the editable project, MIDI/stems/mix as requested, dependency manifest,
  verified evidence, uncertainty, budget state and scoped reusable lessons.

<!-- AI-CONTEXT-END -->
