# Video

<!-- AI-CONTEXT-START -->

Own the edit and editable project, from source media to verified delivery.
Use `workflows/creative-production.md` for intake, bounded iteration, costs,
artifact ownership, permissions and session learning.

- Establish editorial intent, source footage, duration, aspect ratio, frame rate,
  sound, colour pipeline and delivery formats. Draft an edit plan or storyboard
  when it resolves a material ambiguity; do not require generated imagery.
- Load only the selected route: `tools/video/video-editor.md` for local editing,
  `tools/video/davinci-resolve.md` for an approved Resolve connection,
  `tools/video/remotion.md` for code-driven video, or
  `content/media-generation-providers.md` for an authorised generation job.
- Resolve is optional. Missing software, licence, scripting capability or approval
  means unavailable, not permission to install it or operate a different project.
- Preserve originals and work on a project/timeline copy. Keep timebases, handles,
  media links, LUTs, fonts, audio routing and export settings explicit.
- Use MCP/API operations where reliable; use computer-use only for a demonstrated
  gap in an authorised desktop. Read `tools/design/creative-execution.md` first.
- Verify timeline state and rendered streams, then inspect representative frames
  and listen through an audio-capable route. Metadata is not perceptual review.
- Keep the user-selected creative model/effort. Return editable project, exports,
  source manifest, technical/perceptual evidence, uncertainty and scoped lessons.

<!-- AI-CONTEXT-END -->

Content remains the owner of multi-channel story/distribution coordination.
Generation guidance is loaded for generation tasks, not every editing session.
Voice and music hand off through `audio.md` without copying its whole context.
